## 📖 About This Project

This is a **front-end clone** of [SPYLT Milk](https://www.spylt.com) — an Awwwards-winning website known for its bold animations, smooth scroll interactions, and immersive visual storytelling.

I recreated this site from scratch to sharpen my skills in **GSAP animation**, **React component architecture**, and **modern CSS techniques** like clip-path and scroll-triggered effects.

> 🏆 Inspired by the original SPYLT website — all credit for the original design goes to the SPYLT team.

## ✨ Features Recreated

- 🎞️ **GSAP ScrollTrigger & ScrollSmoother** — silky smooth scroll experience
- ✂️ **Clip-path animations** — cinematic section reveals
- 📌 **Pinned sections** — elements that lock during scroll
- 🔤 **Text reveal animations** — staggered letter/line entrances
- 🌀 **Parallax effects** — depth and immersion on every scroll
- 🎠 **Flavor slider** — interactive product carousel
- 📹 **Video testimonial cards** — tilted card stack with hover interactions
- 📱 **Fully responsive** — mobile & desktop optimized

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/GSAP-Awwwards-Website.git

# 2. Navigate into the project
cd GSAP-Awwwards-Website

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.
